### 3. Bug Fixes Found During Development

| Bug | Root Cause | Fix |
|-----|-----------|-----|
| Wrong paper ranked first for Mimi query | Stop words inflating BM25 scores on common passages | Added 15-word stopword filter to query tokenization |
| Reranking reduced scores | `0.6×bm25 + 0.4×rerank` reduced perfect BM25 score | Changed to multiplicative formula `norm_bm25 × (1 + boost)` |
| Stand-in refused all questions | Keyword matching ran on full prompt including paper passages, triggering unanswerable patterns | Extract only the QUESTION section after "QUESTION:" split |
| Config couldn't find `.env` | Pydantic-settings resolved `.env` relative to CWD, not project root | Set `env_file = PROJECT_ROOT / ".env"` |
| Model verification | Checked active models via `/v1/models` | Selected and verified `openai/gpt-oss-20b` |
| `Optional` not imported | Missing import in `measure_real_groq.py` | Added to import |
